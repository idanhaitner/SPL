Glossary

stack

The LIFO region of automatic storage, one activation frame per call, freed when the call returns.

The memory model

heap

The region of dynamic storage obtained with new and released only by a matching delete.

The memory model

pointer

An object whose value is the address of another object, or null.

Pointers and references

reference

A name bound to an existing object. It cannot be null and it cannot be reseated.

Pointers and references

destructor

The special member function that runs when an object's lifetime ends and that frees what the object owns.

Rule of three

copy constructor

The constructor that builds a new object as a deep copy of another of the same type.

Rule of three

assignment operator

The operator that replaces an existing object's resources with a copy of another's, and that must stay safe if the two are the same object.

Rule of three

move constructor

The constructor that steals a source object's buffer and leaves that source empty so its destructor frees nothing.

Rule of five and zero

RAII

Binding a resource's lifetime to an object's lifetime, so the destructor is the release.

Rule of five and zero

unique_ptr

A smart pointer that owns one object, cannot be copied, and can be moved.

Rule of five and zero

shared_ptr

A smart pointer that shares ownership through a count and deletes the object when the count hits zero.

Rule of five and zero

virtual function

A member function whose implementation is chosen from the dynamic type of the object, through the vtable.

Inheritance and polymorphism

vtable

The per-class table of virtual-function addresses. Each object holds a pointer to its class's table.

Inheritance and polymorphism

invariant

A condition that is true of an object whenever no method of the object is running.

Design by contract

precondition

What the caller must make true before a method runs. The method may assume it.

Design by contract

postcondition

What the method guarantees when it returns, provided the precondition held.

Design by contract

thread

A sequential flow of execution that shares the process heap with the other threads.

Concurrency

deadlock

A wait cycle in which each thread holds a lock the next thread needs.

Concurrency

livelock

Threads keep changing state in response to each other and never make progress.

Concurrency

starvation

A thread that is ready to run is passed over indefinitely by the scheduler or by the lock.

Concurrency

TCP

A connection-oriented, reliable byte stream. A read returns some of the bytes, not necessarily one message.

Networking

UDP

A connectionless datagram protocol. There is no accept, and a datagram arrives whole or not at all.

Networking

reactor

One thread that waits in select and dispatches ready non-blocking channels.

The reactor

selector

The Java NIO object that reports which registered channels are ready to read or write.

The reactor

serialization

A representation of an object as a byte sequence that records its type, the shape of its fields, and the field values.

Serialization

primary key

The column or columns that identify one row of a table.

Persistence and SQL

foreign key

A column whose values must equal a key of another table, the relational form of a pointer.

Persistence and SQL
